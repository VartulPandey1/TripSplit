# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in **TripSplit**, please do **NOT** open a public issue on GitHub.

Instead, please send an email with detailed reproduction steps to the project maintainers or open a private advisory via GitHub Security Advisories.

We take security issues seriously and will respond promptly with a triage and patch timeline.
